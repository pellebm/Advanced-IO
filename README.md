# Advanced-IO

Repository for following the **Advanced IO** course at the University of Copenhagen (Fall 2026).

## Structure

- `exercises/` – course exercises and solutions
- `project/` – exam project work and final hand-in material

## Workflow

1. Add each exercise in `exercises/` (for example `exercises/ex01`, `exercises/ex02`, ...).
2. Develop the exam project in `project/`.
3. Keep notes, code, and submissions organized by folder to make hand-in straightforward.
